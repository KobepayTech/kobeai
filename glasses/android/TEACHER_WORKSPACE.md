# MoYoung teacher workspace

MoYoung / DA ECHO is selected in Connections in the Android companion. Pair once,
then the app remembers the BLE address for automatic reconnection. Pause and
Forget pairing remain available. Phone-camera use still works without glasses.

The existing teacher workspace, school-server sign-in, authenticated frame upload,
marking review and phone speech remain in place. No Rokid credentials are requested.
See [MOYOUNG.md](MOYOUNG.md) for the experimental capture path and hardware gates.
